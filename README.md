# CivicEvents – Accessible City Events & Services Portal

Frontend for the CivicEvents+ API, built with HTML, Tailwind CSS and jQuery.

Residents can browse and register for city events, leave feedback, listen to audio announcements and watch captioned promo videos. Administrators manage all content, users and notifications from a dashboard.

- **Setup, running instructions and backend connection:** [frontend/README.md](frontend/README.md)
- **Backend API:** [backend/README.md](backend/README.md) (runs at `http://localhost:4000`)
- **Demo video:** [video-demo/README.md](video-demo/README.md)

## Quick start

1. Start the backend (see `frontend/README.md`, section 1).
2. Serve the `frontend` folder, for example with VS Code Live Server or `npx http-server frontend -p 5500`.
3. Open `http://localhost:5500` and sign in.

The API base URL is set in `frontend/assets/js/config.js`.
